# Сборка .ipa без Mac через GitHub Actions (бесплатно)

Этот способ собирает **неподписанный** .ipa на облачном Mac (GitHub). Затем вы подписываете его своим сертификатом через Esign.

## Шаг 1. Создать аккаунт GitHub
1. Зайдите на https://github.com и зарегистрируйтесь (бесплатно).

## Шаг 2. Создать репозиторий
1. Нажмите **+** → **New repository**.
2. Имя: `WaiterBolt`. Видимость: **Public** (чтобы GitHub Actions был бесплатным; приватные репо имеют лимит минут).
3. Нажмите **Create repository**.

## Шаг 3. Загрузить файлы проекта
Вариант А (через веб):
1. На странице репозитория нажмите **Add file → Upload files**.
2. Перетащите ВСЁ содержимое папки `WaiterBolt/` (включая скрытую папку `.github` и файл `project.yml`). 
   - Важно: папка `.github` должна попасть в репозиторий. Если интерфейс не показывает скрытые файлы — используйте вариант Б.
Вариант Б (через git, если установлен):
```bash
cd WaiterBolt
git init
git add .
git commit -m "initial"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/WaiterBolt.git
git push -u origin main
```

## Шаг 4. Запустить сборку
1. На странице репозитория откройте вкладку **Actions**.
2. Слева выберите **Build IPA**.
3. Нажмите **Run workflow** → **Run workflow** (зелёная кнопка).
4. Подождите 5–10 минут. Появится зелёная галочка.

## Шаг 5. Скачать .ipa
1. Откройте завершённый запуск (клик по нему).
2. Внизу в разделе **Artifacts** найдите `WaiterBolt-ipa`.
3. Скачайте архив, распакуйте — внутри будет `WaiterBolt.ipa`.

## Шаг 6. Подписать через Esign
1. Перенесите `WaiterBolt.ipa` на iPhone (через AirDrop, iCloud Drive, Telegram «Сохранить в Файлы»).
2. Откройте Esign → выберите .ipa → подпишите вашим сертификатом → установите.

## Если сборка упала (красный крестик)
- Откройте лог (клик по запуску → build) и посмотрите ошибку.
- Частые причины: не загрузилась папка `.github` (проверьте, что workflow есть во вкладке Actions); версия Xcode на runner не поддерживает SwiftData (unlikely, macos-latest свежий).

## Ограничения
- GitHub Actions для публичных репо бесплатен, но есть лимит ~2000 минут/месяц (одна сборка ~10 мин — хватит на 200 сборок).
- Неподписанный .ipa не запустится без подписи через Esign/AltStore.
- При обновлении кода просто повторите шаги 3–5.
